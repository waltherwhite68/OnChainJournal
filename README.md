# On-Chain Journal

A simple smart contract that allows users to store daily logs on-chain.

## Features
- Daily log entries
- Streak tracking
- XP system

## Contract Functions

- logEntry(string text)
- getEntries(address user)
- getStreak(address user)
- getXP(address user)

## Use Case

Users can write daily on-chain logs to build a verifiable activity history.

## Network
Base Network
